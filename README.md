A deterministic Monte Carlo forecaster simulates future market caps for the strongest observed coins, using recent trends, volatility and crash risk to estimate the top five at each place. It produces coin placement probabilities and market cap size distributions from make.fun history without network access.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
